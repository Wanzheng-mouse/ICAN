# 第五阶段完成说明：方案进化与运行报告

第五阶段已经从静态演示页调整为真实后端闭环，页面不再使用“假应用成功”或伪造文件下载。

## 已完成

- 仿真页使用真实 `simulationId` 创建进化任务，并保存 `evolutionId` 后跳转。
- 进化页读取后端诊断、基线指标和优化指标，展示完成率、时长、拥堵和能耗的前后对比。
- 版本趋势由真实版本列表与真实指标计算，不再读取不存在的 DTO 字段。
- “应用为新场景”会从原仿真场景创建独立的进化场景，写入动态优先级、速度系数、充电阈值和队列均衡参数，并返回编辑器继续修改。
- 应用接口具备幂等性：重复点击返回同一个进化场景，不会不断生成重复场景。
- 进化动作会区分“待应用/已应用”，不再在尚未执行时显示为已完成。
- 进化页具备加载、缺少 ID、无权限、后端错误和重试状态。
- 报告页的 KPI、趋势、异常、场景排名、履约、设备利用率和回放数据均关联真实 `simulationId`。
- 仿真实时流持续保存最多 300 个指标快照；趋势、履约、设备里程、任务量和场景排名由这些快照与当前运行数据派生，不再使用固定演示曲线。
- PDF 由后端生成并由浏览器下载；没有真实生成能力的格式保持禁用，不伪造导出成功。
- 只读角色可以查看被授权项目的数据，但不能触发进化或导出 PDF。
- 后端进化与报表接口全部执行项目成员权限校验，PDF 导出写入审计日志。

## 验收路径

1. 登录后创建项目并创建/应用场景。
2. 在场景编辑器保存并创建仿真。
3. 启动仿真，等待实时指标更新。
4. 点击“进化引擎”，确认进化页显示真实前后指标。
5. 打开运行报告并下载 PDF。
6. 在进化页点击“应用为新场景”，确认进入新场景编辑器，项目工作区同时出现该场景。
7. 用只读成员登录，确认可以查看、不能控制、应用或导出。
