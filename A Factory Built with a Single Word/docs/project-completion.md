# ICAN 项目完整交付说明

## 交付结论

当前代码已经形成可独立运行的无人仓仿真决策平台 MVP，而不是互不关联的页面集合。核心业务链为：

`注册/登录 → 项目与成员 → 模板/场景 → 校验与版本保存 → 创建仿真 → 实时状态流/历史快照 → 异常注入 → 方案进化 → 应用为新场景 → 对比仿真 → 运行报告/PDF → 通知与审计`

## 六阶段完成范围

| 阶段 | 完成能力 |
| --- | --- |
| 1. 平台基础 | 登录、注册、找回密码、账号中心、搜索、通知、项目创建、路由认证、统一错误结构 |
| 2. 场景与项目 | 项目工作区、资料上传下载、模板应用、场景读取保存、项目深链、成员协作与角色 |
| 3. 场景编辑 | 组件编辑、画布操作、属性配置、严格校验、自动布局、乐观锁与历史版本 |
| 4. 仿真运行 | 持久化离散事件引擎、AGV 安全距离与车道、任务生命周期、电量/充电/拥堵/能耗、实时 WebSocket、批量运行、三维数字孪生 |
| 5. 进化与报告 | 12 轮候选仿真选优、数据驱动编排、策略应用与模板保存、版本趋势、独立新场景、矢量图表 PDF、导出权限 |
| 6. 交付保障 | REST/WS 权限、断线续跑、完成事件、业务通知、管理员审计页面、固定种子、测试、容器、CI、迁移记录 |

## 完整业务验收

1. 注册新账号，登录后编辑个人资料、偏好并验证密码修改。
2. 创建项目，上传订单/规则文件，添加一个可编辑成员和一个只读成员。
3. 应用模板或创建空场景，编辑组件，执行校验、自动布局、保存并查看版本历史。
4. 从已保存场景创建仿真，启动、暂停、恢复、注入异常，确认实时指标和事件同步变化。
5. 断开实时连接后重新连接，确认运行时间和指标从后端继续而非归零。
6. 等待仿真完成，在通知中心进入报告；检查真实趋势、履约、设备利用率、异常和回放数据。
7. 创建进化分析，检查基线/优化对比，点击“应用为新场景”，在编辑器查看新参数并创建对比仿真。
8. 下载 PDF；使用只读成员确认只能查看；使用管理员进入审计日志确认关键操作均可追踪。

## 启动方式

### 本地开发

首次启动：

```powershell
.\scripts\start.ps1 -Install
```

后续启动：

```powershell
.\scripts\start.ps1
```

### 容器运行

```powershell
docker compose up --build
```

- 平台：<http://localhost:8080>
- API 文档：<http://localhost:8000/docs>
- 演示管理员：`admin / ican2026`

## 数据和安全边界

- 默认数据库为 SQLite，数据与上传文件在 Docker 命名卷 `ican_data` 中持久化。
- 生产环境必须修改演示密码、关闭重置令牌回显、限制 CORS 来源并备份数据卷。
- 只读成员能查看授权项目的仿真、进化和报告，但不能修改场景、控制仿真、注入异常、触发进化或导出报告。
- 管理员审计接口为 `GET /api/v1/audit-logs`。

## 当前产品边界

本次交付是“可运行、可联调、可测试、可部署”的软件产品 MVP。当前仿真由固定随机种子和持久化离散事件模型驱动，可复现任务分派、运动、装卸、返回、充电、避碰、拥堵与能耗；它仍不等同于经过现场标定和安全认证的工业物理引擎。进入真实仓库生产部署时，还应对接 PLC/WCS/WMS 协议、现场地图与设备参数，并将 SQLite/本地文件替换为 PostgreSQL、对象存储和工业可观测平台。
